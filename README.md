# ioquake3-PS3

A port of [ioQuake3](https://github.com/ioquake/ioq3) to the PlayStation 3,
using [PSL1GHT](https://github.com/ps3dev/PSL1GHT) and a custom GL-to-RSX
translation layer (OpenGL 1.1 fixed-function to GCM/RSX).

## Status

- Boots, loads maps, enters gameplay with bots
- All textures render correctly (map, icons, models, particles)
- Networking works (LAN discovery, internet server browser, master server)
- DualShock 3 with dual-stick analog input
- Cinematic (intro video) playback with audio
- 60 fps vsync-locked at 720p

## Prerequisites (Windows)

### 1. Build the PS3 toolchain

Build and install [ps3toolchain](https://github.com/ps3dev/ps3toolchain)
(all 9 steps) into `/opt/ps3dev` using devkitPro MSYS2:

```
C:\devkitPro\msys2\msys2_shell.cmd -msys
```

> **Note:** You must use devkitPro's MSYS2, **not** stock MSYS2 (`C:\msys64`).

After building, verify the environment:

```bash
export PS3DEV=/opt/ps3dev
export PSL1GHT=$PS3DEV
export PATH=$PS3DEV/bin:$PS3DEV/ppu/bin:$PS3DEV/spu/bin:$PATH
ppu-gcc --version    # should print powerpc64-ps3-elf-gcc 7.2.0
```

### 2. Clone ioQuake3

Clone the upstream ioQ3 repo **alongside** this folder (not inside it):

```
projects/
├── ioq3/             ← git clone https://github.com/ioquake/ioq3.git
└── ioquake3-PS3/     ← this repo
```

If you want a different layout, adjust `IOQ3_DIR` in the Makefile.

### 3. (Optional) Install Cg Toolkit

Only needed if you modify the `.vcg` / `.fcg` shader source files in
`code/gl/shaders/`. Download [Cg Toolkit 3.1](https://developer.nvidia.com/cg-toolkit)
(32-bit `cgc.exe`).

## Building

### Step 1 -- Patch ioQ3 (run once)

```bash
cd ioquake3-PS3
bash apply_patches.sh
```

This applies small idempotent patches to the upstream ioQ3 source (zero-length
JPEG guard, PS3 network fixes, cinematic re-enable, etc.). Safe to re-run.

### Step 2 -- Build

```bash
make          # Build ELF only
make self     # Build ELF + EBOOT.BIN (fake SELF)
make pkg      # Build ELF + EBOOT.BIN + installable PKG (recommended)
make clean    # Remove all build artifacts
```

**Output:** `build/ioquake3_ps3.pkg`

> **Note:** When changing build options, run `make clean` first to ensure all
> objects are rebuilt with the correct flags.

## PS3 directory layout

```
/dev_hdd0/game/IOQ3PS300/
├── PARAM.SFO              ← generated by build
├── ICON0.PNG              ← XMB icon (required for visibility)
└── USRDIR/
    ├── EBOOT.BIN          ← generated by build
    └── baseq3/
        ├── pak0.pk3       ← from your Quake III Arena disc / purchase
        ├── pak1.pk3
        ├── ...
        └── pak8.pk3
```

**You need the original Quake III Arena data files** (`pak0.pk3` through
`pak8.pk3`). On Steam, these are found in
`steamapps/common/Quake 3 Arena/baseq3/`.

## Installing on PS3

### Option A: PKG install (recommended)

1. Build with `make pkg`.
2. Copy `build/ioquake3_ps3.pkg` to a USB drive.
3. Install via Package Manager on your CFW/HEN PS3.
4. FTP the `baseq3/*.pk3` files to
   `/dev_hdd0/game/IOQ3PS300/USRDIR/baseq3/`.

### Option B: FTP install

1. Build with `make self`.
2. FTP `build/pkg/USRDIR/EBOOT.BIN` to
   `/dev_hdd0/game/IOQ3PS300/USRDIR/EBOOT.BIN`.
3. FTP `build/pkg/PARAM.SFO` to `/dev_hdd0/game/IOQ3PS300/PARAM.SFO`.
4. FTP `build/pkg/ICON0.PNG` to `/dev_hdd0/game/IOQ3PS300/ICON0.PNG`.
5. FTP the `baseq3/*.pk3` files to
   `/dev_hdd0/game/IOQ3PS300/USRDIR/baseq3/`.
6. Reboot the PS3 (or restart the XMB) to refresh the game list.

## Recompiling shaders

Only needed if you modify the `.vcg` / `.fcg` source files in
`code/gl/shaders/`.

```bash
cd code/gl/shaders
./compile_shaders.sh

# If cgc.exe is not in a standard location:
CGC_PATH=/path/to/cgc.exe ./compile_shaders.sh
```

This uses a two-step pipeline:
1. `cgc.exe` (Cg Toolkit 3.1, 32-bit) compiles to ARB assembly
   (`-profile vp40` / `fp40`)
2. `cgcomp -a` (PSL1GHT, assembly mode) converts to RSX binary
   `.vpo` / `.fpo`

The compiled binaries are embedded into `code/gl/ps3gl_shader_data.h` as
C arrays.

## Memory budget

| Region | Size | Location | Notes |
|---|---|---|---|
| Hunk (`com_hunkMegs`) | 80 MB | Main RAM (XDR) | Maps, shaders, models |
| Zone (`com_zoneMegs`) | 24 MB | Main RAM (XDR) | Dynamic allocs, zlib inflate |
| Sound (`com_soundMegs`) | 8 MB | Main RAM (XDR) | Audio buffers |
| RSX IO buffer | 32 MB | Main RAM (XDR) | GCM command buffer + control |
| Framebuffers | ~7 MB | Video RAM (GDDR3) | Two 1280x720 ARGB + Z24S8 |
| Vertex ring buffer | 4 MB | Video RAM (GDDR3) | Per-frame vertex data |
| Textures | ~40 MB | Video RAM (GDDR3) | RSX texture heap |
| BSS + code | ~10 MB | Main RAM (XDR) | Static data + executable |

Total: ~162 MB of 256 MB main RAM, ~51 MB of 256 MB video RAM.

## Important notes

- All `.sh` scripts **must** have LF line endings (not CRLF). Git can mangle
  these on Windows -- use `.gitattributes` or `dos2unix`.
- The `-mno-altivec` compiler flag is required. PS3's Cell SPE is not AltiVec.
- `MAX_CLIENTS` is reduced to 8 (from 64) to fit PS3 memory constraints.
- IPv6 code compiles via stub types but is non-functional at runtime
  (PSL1GHT has no IPv6).
- Library link order matters: `-lsysmodule` must come after `-lnet`.
